# POLCA-Wranglr

**POLCA-Wranglr は、**Polars**（Rust 実装の超高速 DataFrame
エンジン）を処理コアに採用したデスクトップ型のデータ加工アプリケーションです。**

**✅ ビッグデータ（センサーデータなど）を、ノーコードで、超高速処理**  
**✅ データプロファイリング × データラングリング を１つのデスクトップアプリで完結**  

Python や SQL の知識がなくても、直感的な GUI だけで ──

- 生データの**プロファイリング・探索的データ解析（EDA）**
- データの**クリーニング・変換・整形**
- 機械学習・分析用の**クリーンデータ生成**

── をすべて実現します。

## ２つのコア機能

### 🔍 データプロファイリング（EDA）

「このデータ、何が入っているのか？」を一瞬で把握する。

OSSの **Zarque-profiling**
をそのまま統合。ボタン一つで、ビッグデータに対する包括的な品質レポートを自動生成します。

✅ 各列のデータ型・欠損値・ユニーク値数  
✅ 数値列の分布ヒストグラム  
✅ 文字列列の頻度上位値  
✅ 列間の相関係数マトリクス  
✅ 部分データ表示  

── 数千万行のビッグデータでも、基本統計を高速に出力。まず全体像を把握してから深掘りする、プロのワークフローをそのまま実現します。

### 🔧 データラングリング（クレンジング）

「品質の高い使えるデータ」に変換するための、すべての道具がここにあります。

✅ フィルタリング ... 複数条件（AND/OR）・11 種の比較演算子  
✅ ソート ...　　　　 複数キー・昇順/降順  
✅ 文字列操作 ...　　 結合・分割・正規表現置換・表記ゆれ吸収（Fuzzy）  
✅ 型変換 ...　　　　 Int/Float/String/Boolean/Date など全型対応  
✅ 異常値処理 ...　　 クリッピング（置換・除外）  
✅ カテゴリ化 ...　　 ビニング（binning）・Categorical 型変換  
✅ 重複削除 ...　　　 全列・指定列・先頭/末尾保持  
✅ 結合 ...　　　　　 Join（Inner/Left/Outer/Cross/Semi）+ Star Join + Union  
✅ ピボット ...　　　 横持ち変換・縦持ち変換・集計ピボットテーブル  
✅ 特徴量生成 ...　　 One-Hot/Label Encode/正規化/対数変換/多項式  
✅ サンプリング ...　 10%〜90%（再現シード付き）  
✅ 列操作 ...　　　　 追加・削除・複製・名前変更・四則演算　　

── 生データを分析や機械学習に直接投入できるクリーンな形式へ。GUI
操作だけで、コードゼロで変換します。
